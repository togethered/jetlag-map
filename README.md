# jetlag-map

A custom-made map designed specifically to facilitate playing [_Hide + Seek_][game] from [_Jet Lag: The Game_][jet-lag] in San Francisco. Read our [motivation for making this][sean-blog].

[game]: https://store.nebula.tv/products/jet-lag-the-game-hide-and-seek-transit-game
[jet-lag]: https://www.youtube.com/playlist?list=PLB7ZcpBcwdC7gTO_IVdiBv8nVPLKbqNa4
[sean-blog]: https://sheeptester.github.io/longer-tweets/hide-seek/

## Development

You need [Bun][bun].

[bun]: https://github.com/oven-sh/bun/pull/30412

```sh
# Install dependencies
bun install

# Develop locally at http://localhost:3000/ 💅
bun run serve

# Bundles to dist/
bun run build
```
